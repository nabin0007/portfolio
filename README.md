# Portfolio

This repository contains a simple, responsive starter portfolio website.

Files added:

- `index.html` — the main page (About / Projects / Skills / Contact)
- `styles.css` — basic styling
- `script.js` — tiny JavaScript for helpers (year, smooth scroll)

How to customize

1. Edit `index.html` to replace the placeholders with your name, bio, project list, and contact details.
2. Update `styles.css` if you want different colors or fonts.
3. Commit changes directly in GitHub or clone the repo locally:

   git clone https://github.com/nabin0007/portfolio.git
   cd portfolio
   # edit files, then
   git add .
   git commit -m "Customize portfolio"
   git push

Publish with GitHub Pages

This repo can be hosted with GitHub Pages. By default the Pages URL will be:

https://nabin0007.github.io/portfolio/

Go to the repository Settings → Pages and ensure the source is the `main` branch (root). Changes pushed to `main` will publish automatically.
